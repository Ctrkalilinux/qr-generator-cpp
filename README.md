# QR Generator in C++

Pequeña aplicación desarrollada en C++ que permite generar un código QR de forma simulada a partir de un texto ingresado por el usuario.

## 📌 Descripción

Este proyecto solicita al usuario un texto desde la consola y simula la generación de un código QR.  
Fue desarrollado como práctica para reforzar conceptos básicos de:

- Entrada y salida en C++
- Manejo de strings
- Compilación con g++
- Uso de Git y GitHub

## 🚀 Cómo compilar y ejecutar

### 1️⃣ Compilar

```bash
g++ main.cpp -o qr
